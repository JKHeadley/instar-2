## Closing block

simplestRobustRoute: the required outcome is that an operator's plain question is answered rather than held behind a memory correction whose judgment can no longer be reached. The simplest robust route is one predicate on the existing journal projection, settled through the existing `memory-undecided` record: a `memoryPending` turn an accepted frontier has already passed cannot be decided by any later summary, so it is settled undecided. This proposal is that route. Alternatives considered and rejected: (a) bounding the "earlier turn pending" ordering hold by a timer, which treats the symptom, adds a clock-dependent release at the centre of the correction discipline, and would still leave the root with 13 permanently unresolved corrections and its summary passes repeating; (b) making a held turn eligible for the minimal responder, which would deliver a truthful limited reply inside the floor but leaves the wedge in place and the ordinary answer never arrives; (c) widening `settleExhaustedEdit`'s counter to survive an accepted summary, which changes what "exhausted under the current base" means for every other consumer of `summaryFormatFailures`. No added machinery: no new record kind, store, prompt, gate or model call.
80/20: 0 must-fix, 2 notes. (a) `limitedReason` still returns null for any held turn, so while a correction is genuinely and reachably pending its own reply can still pass the 120 s floor with only its held notice; that is the designed held-notice path and a separate unit if the floor is to cover held turns too. (b) The live root's summary frontier at 6232684 was failing `malformed` repeatedly (37 malformed over 52 summary calls); this change stops that failure from wedging the answer path, but the malformed summary reading itself is a separate defect class and is not touched here.

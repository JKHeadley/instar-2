## Closing block

simplestRobustRoute: the required outcome is that a cancellation the answer states plainly, with the operator's own words, is applied, and that one it cannot tie to his words is refused with the honest refusal. Both already exist and work on a turn whose memory question was settled; the only thing preventing them on an undecided turn was that an omitted memory field counted as a malformed decision and wiped the verified withdrawal. The simplest robust route is to stop counting that omission as malformed when the same decision has stated that the message withdraws a request. This proposal is that route: one condition beside the existing memory default. No new field, row, model call, prompt text, retry or flag. Start guard: only a verified-operator turn already settled memory-undecided with a non-empty cancelReminders array is affected. End-state guard: the existing quote check decides apply versus refuse, and the requests it does not withdraw still fall due once (replayed). Limit guards: the existing ten-citation and quote-length bounds and the unchanged reply and call caps.
80/20: 0 must-fix, 2 notes — (1) a compound message that withdraws a request and also corrects a fact, on a turn whose summary already gave up, records the cancel and not the correction if the model omits memory, without the reply saying the correction was not recorded; before this change both were lost; (2) the reviewer can still trim a fixed infrastructure notice into a fragment (decision cancel2-leave-the-notice-and-withhold), reported to the desk.

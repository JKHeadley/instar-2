## Closing block

simplestRobustRoute: the required outcome is that the architecture check reaches a true verdict on an unchanged main, on any machine, without giving up a check it used to make. The simplest route through the existing mechanisms is exactly what was taken: satisfy the one unstated precondition the check already had (the generated core it reads) with the repository's own tsc and the config `npm run build` uses, and ask the one host-bound question only where the declaration says it applies. No machinery is added — no new register entry, no cache, no skip list, no new rule id, no change to the closure or digest functions — and the only new seam is two injected parameters that make both sides of the build decision testable. The simpler-still route, prefixing `npm run lint` with a build, was rejected because it leaves the bare command named by the brief and the charter failing on every fresh worktree, which is the condition that produced this report. A platform-wide skip of the whole certification block was rejected because it would stop checking closure completeness and conformance bytes off-platform, which is a real gap this change deliberately does not open. Applicable guards: start — the check runs only when `dist/index.js` is absent, so a built tree is untouched; end-state — a build that cannot be produced is an R105 finding, never a silent pass; limit — one build attempt, never a retry loop.
80/20: new tests prove both sides of every decision against the real committed declarations and the real composition bytes, not stubs: a runtime that is not this one is flagged on the platform the tuple names and not flagged off it; an off-platform tuple with its declared runtime carries no finding at all; byte drift in a source file (tests/preview/self-host-owners.ts) and in the built core (dist/index.js) is still caught off-platform; a present build is not rebuilt, a build that produces the core passes, and a build that fails or that claims success without producing the core is the finding, quoting tsc's first line. `node scripts/check-architecture.mjs` exits 0 from a removed `dist/`; tsc --noEmit, register:check and the neighbouring architecture suites (tests/types/architecture.test.ts, tests/facts/architecture.test.ts, tests/register/wiring.test.ts, tests/types/compile.test.ts, tests/types/measurement-subjects.test.ts, tests/types/historical-comparison.test.ts, tests/assembly/tool-inventory.test.ts, tests/preview/model-call-boundary.test.ts) pass.

## Closing block

simplestRobustRoute: the required outcome is that the text a model is given never denies a capability the same text lists, and that a cancellation rests on the operator's withdrawal rather than on the agent's own reasoning. The simplest robust route is to correct the two sentences that misled the model and to add one evidence check to the decision validation that already runs — and that is this route. No sentinel, no second model call, no review layer and no keyword matcher is added; the quote check reuses the exact-quote pattern the protocol already uses for promises, fulfilments and memory, and it fails toward the conservative default (every request stays open). The added machinery is one predicate and two named bounds; the credible failure it prevents is the recorded one, an agent silently withdrawing an obligation its principal never withdrew. The guidance correction alone would not have prevented it, because the shape that admitted it required no evidence at all. Start guard: the cancellation only runs on a verified-operator turn with requests listed. End-state guard: the open-request list and the reply's own stated outcome. Limit guards: at most ten cited withdrawals, each 6 to 400 bytes. No autonomous-completion claim is made here.

## Closing block

simplestRobustRoute: the required outcome is a durable record of each memory failure (asked, returned, truth, cause) and a structural change that makes the next recall better, without a new engine. The simplest robust route is this one: the journal already keeps the evidence (corrections naming restating replies, each answer's packet grounding, the summaries), so the record is a projection over it; the only new input is one optional field on the existing answer call, offered by structure where the old path cannot see a forgotten fact (an answer given without part of memory verbatim); the lessons are two bounded inputs to the existing recall owner (meaning cues and pinned candidates). No new store, journal frame, model call, timer or gate. A simpler route, recording only from corrections, misses the commonest failure (an "I don't know" for a fact the journal holds), which the recorded room shows twice. Start guard: the structural offer and the verified-operator check; end-state guard: replay validation of every stored report; limit guards: twelve cue words per source, four pins, the existing packet drop order and call cap. Unattended shipped-path result: the worker-level tests drive a real journal and worker through the recorded room: forgotten answer, reminder, recorded failure, then the same question recalls the fact, before and after a restart.

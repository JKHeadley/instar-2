Outcome: Proof room two, 2026-10-02 (live build cint-L23 e26a8c1b, lanes/pipeline/live-proof/results/recallrank-evidence-20261002): the fact "My garden shed padlock code is 2958." was in the meaning index, and the question "What number opens the little hut where I keep my rakes?" recalled five other turns. This change does two things and deliberately not a third. (1) It pins the mechanism in a test replayed from the recorded texts: recall reaches a summarized message only through a stem the question shares with the message, its reply, or its generated index terms; two verbatim real outputs of the build's own index question for the room's messages show the fact's terms restating the message ("padlock code", "shed combination"), sharing no stem with the question in one sample and only "number" in the other, while the unrelated commitments question scores through "open commitments". (2) It fixes one real indexing defect those same outputs expose: a term carrying a clock time ("12:09 am alert") is refused by the stored-term check, and the write path refused the message's whole term list with it, leaving the message with no meaning terms. The write path now keeps the usable terms and drops only the unusable one. (3) It does NOT make the recorded question reach the fact when nothing shares a stem: that needs something that reads the question by meaning on the read path, which the brief's limits exclude (no new model call per turn) and which Rule 11 requires; the conflict is reported to the desk rather than settled here.

## Closing block

simplestRobustRoute: the required behaviour for the part shipped is that a message whose writer returned usable meaning terms gets them stored. The simplest robust route is to check each proposed term with the existing check and keep the ones that pass, at the two places a proposal is read; this proposal is that route, and it adds no machinery beyond one small function. For the recorded miss the simplest robust route is a meaning reading of the question on the read path through the recall owner's existing rerank port; it is not taken here because it spends a model call per turn, which the brief excludes and which is a spend decision above this unit.

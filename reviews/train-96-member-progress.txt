### ELI16
Instar's setup program is written partly in TypeScript, and it brings its own translator for TypeScript (a package called `typescript`). The project listed that translator as "only needed by developers". When someone installs straight from GitHub with one line, npm skips the developer-only packages, so the setup program started, looked for its translator, didn't find it, and crashed before asking anything. I moved the translator to the "needed to run" list. Now the one line downloads Instar, asks the four setup questions, and saves the answers; running it again says it is already set up. A test now checks that everything the setup program loads is on the "needed to run" list, so this can't quietly break again. The README now shows the one line, says honestly that signing in, connecting Telegram and starting the agent aren't built yet, and warns that the npm package called `instar2` belongs to a stranger.

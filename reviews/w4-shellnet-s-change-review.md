## Closing block

simplestRobustRoute: the required outcome is a sandboxed shell that can read the public network (curl, git clone, package installs) while writes, this machine's own network and secrets stay held, and every decision is on the record. The simplest robust route is one intercepting proxy per turn, which the harness sandbox already supports as its external proxy (httpProxyPort), with its own trust root handed to the shell through standard variables, deciding each request by method and path with the existing effect doorway and the existing web-read host rule. Per-tool adapters were the alternative and are not simpler: each re-implements a client, needs commands judged by their words, and leaves every other client without network. Added machinery and the failure each prevents: TLS interception (without it HTTPS hides the method, so writes could not be told from reads, which is why the shell had no network); resolve-then-connect to the checked address (a name re-pointed between check and connect would reach this machine); NO_PROXY emptied (live: the harness's exemption let loopback and private ranges bypass the record); a per-turn root whose key stays in the admission state (a shared or readable key would let a tool impersonate any host to other clients); bounds and lifetime equal to the turn (an unbounded or lingering proxy would outlive stop); the network tools' read-only locations and git environment (live: git could not run in the sandbox). Start guard: the checkpoint starts before launch or the turn fails; end-state guard: the checkpoint closes with the turn and its record is journaled; limit guards: bytes, connections, requests, idle time, the doorway's refusal of writes. Unattended shipped-path result: 11 live tool turns through runToolTurn and the shipped route; the Telegram end-to-end proof is the desk's live-proof step.
80/20: 0 must-fix, 5 notes — a GET can still carry text the model chose and a method-override header passes through; non-HTTP protocols (SSH git, WebSocket) do not reach the network; npm audit and other read-shaped POST APIs are refused; Go TLS clients verify through the system trust service and fail through the checkpoint; the workspace .git protection stays, so repositories are cloned under $TMPDIR.

## Closing block

simplestRobustRoute: the required behavior has two parts. For the retrospective: a pass whose answer fits its budget COMPLETES, records only what the answer really holds, and keeps every case it did not inspect owed. The simplest robust route is to apply the per-duty disposition the validator already has — unavailable, with a note saying why, which w3-retrolive and w3-retrolive2 each introduced for one claim — to the one field that still refused the whole pass, and to state that disposition in the question so both sides name one shape. No new ledger, retry, row kind, flag, classifier or realignment is added; the only new symbol is a note string, read back by the predicate the status line already uses. The deeper route, a duties field that does not depend on the model counting to fourteen, is named and deliberately not built: it changes the answer contract, the question digest and two deployed probe fixtures together, and the analysis showing it is the only route that would make I1b pass is in decision retrocluster-4 for the desk. For I3b: the required behavior is that the agent states a position it has reached instead of only asking. The simplest robust route is one sentence of delivered instruction — an agent with instructions, which Rule 116 prefers for a condition that varies — not a detector for "disputes", which would be a semantic judgement in code. It is placed where it costs nothing on a turn with nothing to dispute, and written to fit both existing size guards rather than moving either. For the two check-side failures the route is the check, not the product: each assertion is rewritten to state the rule's floor in a form both the old and the new product shape satisfy. Start guard: the plan, admission and spend cap are unchanged. End state: a completed pass with honest per-duty dispositions, and a reply that carries its position. Limit guards: the output cap, the call reserve, the always-sent prompt floor, the compact packet bound and the fail direction are all unchanged. Unattended shipped-path evidence: none claimed — the live root was unreachable from this machine, no real-model call was made, and I1b is stated as still failing.

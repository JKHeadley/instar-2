## Closing block

simplestRobustRoute: the required outcome is native tool execution that keeps the secrets, stop and resource floors without removing a tool. The simplest robust route reuses the two checkpoints that already exist: the Seatbelt profile the native shell used and the host resource owner every provider launch passes. Moving the file tools into a worker under that profile closes the post-admission swap and the blocking open in one step; routing the worker through the owner attaches memory, process, CPU and handle ceilings, the stop and verified cleanup. The added parts and the failure each prevents: the worker (a swapped link or FIFO reaching the loop's process), the node literal in the profile (the worker could not start), the stop check after admission (a call run after a latched stop), the streamed fetch body (a whole response allocated before slicing). Start guard: the hook's admission; end-state guard: the owner's verified cleanup and the trace check; limit guards: the owner's ceilings, deadlines, the fetch byte limit.

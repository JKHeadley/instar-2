## Closing block

simplestRobustRoute: the required outcome is that a file the harness opens cannot be an operator file whatever path was admitted. The simplest robust route is the kernel's own check: run the harness as a user that cannot reach those files. Added machinery and the failure each prevents: the launcher (without it the stop cannot reach a process of another user, so the stop floor would break); the census uid and bounded wait (without them the owner would neither bound the harness tree's memory nor know when it is gone); the add-only state directory (without it the harness user could rewrite its own admission config); readiness probe (without it a mis-provisioned machine could silently run with access it should not have, or fail without saying why). Start guard: readiness at launch; end-state guard: the launcher's teardown plus the owner's verified cleanup; limit guards: the existing call reservation, time, CPU, handle and memory bounds. Unattended shipped-path result: the turn and stop cases through runToolTurn and the shipped route on a throwaway root.

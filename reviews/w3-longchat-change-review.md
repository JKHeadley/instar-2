Fix: one exported predicate, continuitySpoken — the sentence is said the first time this context lost verbatim history, when the accounted message is not already answered, when the kind of seam changed, or when the last one's send stayed UNKNOWN, and never twice running with the same words. The durable account is still recorded on EVERY compacted reply, bound by replyDigest to the text actually sent, carrying spoken:false when its prose was withheld; replay refuses both halves of a disagreement between record and sent text.

## Closing block

simplestRobustRoute: (A) The required outcome is that a summarized message is either indexed or its miss is recoverable and visible. The existing mechanisms already carry all of it — an index-only pass, an offered-sources record, a coverage reading — so the route is to relax one filter (full batches only) and turn one boolean (ever offered) into a bounded count, then publish the pending set the journal already knows. The added machinery is the attempt count; the named credible failure it prevents is the live one in a second form: the first partial batch whose terms the writer omits would strand the same messages for good. (B) The required outcome is a faithful disclosure that is not fifty copies of itself. The route is to change what the existing gate asks — not "is this frontier accounted?" but "does this sentence tell the operator something?" — leaving the account, its digest and the packet note exactly as they are. No new store, row kind, model call, flag or surface in either half; the one new durable field is an optional boolean on an existing optional record.
80/20: 0 must-fix, 4 notes — (1) the meaning index still depends on a writer returning terms, so coverage can legitimately stay degraded after both attempts: the honest reading now says the attempts are spent, which is a measurement, not a repair, and a third source of terms (a semantic route) remains the thing worth building; (2) the worker-level disclosure scenarios on this machine settle on a single seam kind, so the summary-to-set-aside transition is proved through the predicate and the room's own recorded summary-basis accounts rather than through a live basis change; (3) an older build replaying a journal written by this one would refuse a silent continuity row, so a rollback wants a fresh room (recorded in the undo field); (4) the 55-byte instruction growth moved two measured byte windows, which is a cost paid in test constants rather than in evidence — the answer packet is unchanged, verified by recall-latency's pin.

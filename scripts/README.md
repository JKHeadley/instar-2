# Build, check and host scripts

Build adapters and repository checks (the register build `build-register.mjs`, `check-architecture.mjs`, the contract-map checks) plus the host-side adapters the launchers load at runtime: `production-boot.mjs` and `production-boot-io.mjs` (the fixed installation's OS ports), `transport-file-storage.mjs`, `effect-file-captures.mjs`, `effect-replica-storage.mjs`, `judgment-captures.mjs`, `host-watch.mjs`, the host watchdog launcher, and `approval-surface.mjs`, the operator's own approval page process, with `operator-dashboard.mjs`, its dashboard (Rule 81's floors are checked by `check-dashboard-floors.mjs`). Durable writers declare their stores beside them in `*.declarations.json`.

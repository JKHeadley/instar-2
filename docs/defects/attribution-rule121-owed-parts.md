# Rule 121 attribution: the parts the first cut does not ship

**Status:** OPEN. The note-write check and optional after-delivery reply records are built. Enforcement of reply attribution and the remaining work below are incomplete.

**Owner:** Echo (agent), as owner of the preview trial's reply review and tool admission. Each part lands as its own unit with its own change-review record.

**What the first part holds:** under `--attribution record|enforce`, every note write (Write, Edit or NotebookEdit on a `.md`, `.markdown` or `.txt` file, and the added prose lines of an `apply_patch`) is checked once per exact text before the file changes. Code proves what code can: the `[source: …]` marker parses, it resolves to a logged message in the journal, the date matches, and the quoted words are in that message. One recorded model judgment (`attribution-judge-2.0-v2`) decides whether the text credits a person and whether the line claims more than the words. Under enforce a refused note is not written and the agent is told how to write it honestly. Without the option nothing changes.

**Reply records:** `--attribution-replies record` independently enables observation of delivered agent replies in the existing serial after-delivery review pass. It enables no note check and accepts no enforce value. Each credited span records its words, person, cited reference when present, and `sourceFound`: whether that reference resolved in this journal. False means no cited source resolved, not that the person never said it. A found source is not proof of authorship or faithful interpretation. Existing verdict/findings remain observations only: no refusal, revision, cut-out or wait before delivery. Off by default. The existing prefilter can miss credits; oversized text, stopped/capped calls and unavailable judgments remain unchecked. Journal reservations prevent paid-call replay after a crash; delivered intents permit recovery before reservation. The full outgoing text remains in its intent even where a recorded span is shortened to 500 characters.

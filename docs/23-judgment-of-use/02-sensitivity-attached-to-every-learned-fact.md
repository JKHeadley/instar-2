## 2. Sensitivity attached before learned facts are used

**Rule — every learned fact has a defined membership and first-use boundary.**
**Checks: P23-NF-03/04/18.** A **learned fact** is an admitted fact whose kind and
producer are registered in the Part 23 source registry as recallable into judgment
contexts. This registry is package configuration enrolled through Three's normal
registration workflow, resolved against source-owner admission and producer
records through public ports; it is not a new core type. Membership begins when
such a fact is admitted. At a pinned source and registry frontier, the population
is exactly the distinct owner-issued fact/version identities satisfying that
predicate, including members never recalled. An unresolved owner result makes
population completeness unknown; a consumer cannot guess membership or silently
exclude unresolved records. Registry changes use the same governed owner workflow
and cannot retroactively remove membership or coverage debt at a pinned frontier.

Raw preserved captures and unprocessed inputs are excluded until admitted as a
registered source fact. Inferred facts, derived summaries and learned judgment
policies are included when admitted from a registered kind/producer pair.
Assessment records themselves and administrative/operational records are excluded:
there is no recursive assessment. Imports and replicas join on owner adoption if
they satisfy the same predicate, carrying or re-deriving their scoped attachments.
Copies with the same owner-issued fact/version identity count once; a separately
admitted derivative has its own identity and contributing source references.

No member may be used in a judgment context — recalled, cited or allowed to guide
an effect — without a scoped SensitivityAssessment reference or an owner-durable
pending obligation attached before that first use. This is the recall boundary
in row 116, applied before the fact enters the consuming context. Assessment
status can be `assessed`, `pending`, `disputed` or `unavailable`; missing evidence
never means harmless or supplies permission. At an attempted first use, persist
the owner obligation before attachment work; a crash before attachment leaves
the fact unused, the obligation durable and reconstruction showing no use.
If durability cannot be established, the fact stays unused and the owner reports
the failed attempt. Only permitted assessment projections travel with recall.

Admission-time attachment is an optional stronger arm through a source owner's
existing public port. It is never required and never a prerequisite on that
owner's admission. A member admitted but never recalled and without an assessment
is `UNASSESSED`, counted in coverage debt rather than an attachment violation.
Backfill may assess these members under current permission; it cannot manufacture
past use or a completed assessment.

Basis: Purpose's wisdom Value and no-silent-loss constraint; rules 7/28/29/33/58;
[R5 §2](research/05-proposals-and-evaluation.md).

| Identity | Immutable assessment id, fact/version, predecessor, assessor, time, source frontier and owner custody reference |
| Who it concerns | Every known affected subject and relationship, owner-verified handles and verification status; possible additional/unknown subjects |
| Source standing | Verified source principal, role, claim/subject scope and authority evidence, separately from credibility, competence and evidence strength |
| Provenance | Direct exchange, observed transcript, secondhand report or inference, with contributing source and assessment references |
| Context | Original purpose/setting, evidenced confidentiality expectations, intended use, audience, freshness and relevant uncertainty |
| Permission | Owner-resolved policy/consent references and versions for private use, processor/provider exposure and disclosure separately; no grant stored as a model guess |
| Sharing harm | Per person and proposed flow: literal/indirect disclosure, severity, estimated likelihood or unknown, reversibility, time horizon and evidence |
| Withholding harm | Per person and option: missed help, broken commitment, misleading omission or delay; distinguish not using from using privately without disclosure |
| Observable action | Timing, participants, destination, tool arguments, recommendation, explanation and combined-fact inference, including permitted knowledge of the audience |
| Defeating evidence | What would overturn the assessment, refresh triggers, next observation owner and pending/disputed/unavailable reason |
| Custody | Visibility by field, allowed processors/readers, retention/pins, availability; rationale can be as sensitive as the fact |

**Rule — sensitivity supplies evidence, never authority.**
**Checks: P23-NF-03/06/10.** Neither a sensitivity label, perceived urgency,
expected benefit, model confidence nor a thankful recipient grants access. B
compares feasible alternatives per affected party; it cannot offset a forbidden
flow with somebody else's benefit. No universal scalar harm sum selects the
winner. A source's verified standing does not prove its factual claim.

Basis: Purpose's wisdom and authority constraint; rules 28/57/86/108.

**Value — initial severity vocabulary.** Agent-owned evaluation setting:
`none observed`, `bounded adverse effect`, `material adverse effect`, `unknown`.
Freeze examples by criterion and subject scope. Material harm means evidenced
confidentiality loss, consequential commitment failure, or comparable harm named
in that criterion; unresolved comparability stays disputed. These categories
group observations by harm category. This grouping is **stratification**; each
group is a **stratum**, so a strong overall result cannot hide a weak group.
The categories do not set permission or an acceptable-risk policy.

Basis: Purpose's wisdom Value and “Who decides what,” bounded by the authority
constraint and rule 57; [R5 §2](research/05-proposals-and-evaluation.md).

**Rule — reuse checks all dependencies, not a time-to-live alone.**
**Checks: P23-NF-04/18.** A use assessment is current only for the same source
frontier, verified identity relations, grant versions, principal/provider,
purpose, audience and observable action. Changes invalidate affected current
support. Derived facts preserve every contributing permission dependency.
Rejected or replaced assessments remain retrievable under restricted custody.
A card can be reused after these checks; a prior contextual conclusion is not
universal. The loss detector uses the same owner-resolved membership identity set
as NF-03, NF-18 and section 7. It joins first-use evidence to attachment/pending
references, reports never-used unassessed members as coverage debt, and raises
owned defects for use without a preceding attachment or broken obligation links.

Basis: Purpose's coherency, trust and no-silent-loss constraint; rules 7/33/90/95;
Part 21 current scope and permission-intersection contract, section 1 Basis.

## 8. Interruption, kill, and recovery

**Rule — stop closes dispatch before waiting on a worker.** Rules 4/29/55/60/63/68;
checks P13-NF-18/36/37/41/42. The independently authenticated emergency stop closes new model,
tool and outward-send admissions immediately through the local stop authority. It does not wait
behind the busy-message queue, a model response, remote quorum or ordinary recovery loop. Ten
then asks `control` to stop the exact worker and its owned descendants. Every signal revalidates
the recorded process start identity; no pattern, remembered PID alone or terminal-wide shortcut
may target a neighbour. Control delivery, process termination and remote effect quiescence are
separate observations. An in-flight remote effect can remain uncertain after the local process
is gone. Report that limit without releasing its exposure or repeating it.

Ordinary interrupt, close and compaction use Eight's current admitted operation and Six's fence
and allocation. If the ordinary path fails, a timer supplies no new authority to act; emergency
stop's independent path still exists. Host cleanup closes dispatch admission even when process
termination fails. A stop arriving during launch/admission must also catch resources acquired
after that request; a late promise resolution must not resurrect the worker.

**Rule — one bounded recovery episode owns the incident.** Rules 38/55/59/60/61/64/68;
checks P13-NF-24/35/37/38/40/46/51/52. Six supplies cadence, backoff, attempt count, elapsed and
resource ceilings, breaker and exit test. The adapter executes one action and reports evidence;
it cannot run a hidden reconnect/respawn loop. The same incident cannot start separate watchdog,
compaction and quota-swap interventions. Applicable critical-pipeline supervision uses Seven's
registered model path inside those bounds; a supervisor never widens a floor.

| Silent-stop class | Detection and safe response |
|---|---|
| Lost launch or input acknowledgement | Reconcile the exact operation and claim; retain uncertainty and pending intake. |
| Permission/trust/selection prompt | Retain the wait. Clear only an exact already-authorized call with an allow-once response bound to that call, prompt digest and incarnation; never an “always allow” change. A detector miss is not clearance. |
| Provider unavailable, quota wall or account expiry | Preserve work and reserved exposure; bounded owner-admitted route or worker replacement, with no implicit scope or budget increase. |
| Protocol loss, probe failure, process exit or reused PID | Unknown stays unknown; recover the exact local handle or admit a new incarnation after reconciliation. |
| Alive without work progress | Exclude bounded external waits and active producer/child work first. Any judgment sees current work evidence; no silence-to-kill shortcut. |
| Context limit or confirmed poisoned vendor history | Supported compaction then rebuild for exhaustion; rebuild without the poisoned handle for confirmed corruption. Retain uncertain effects. |
| Partial/malformed output, empty reply or missing terminal event | Record explicit incomplete/no-reply/unknown status and preserved captures. Do not invent a sent answer or completed run. |
| Hidden helper or unresolved child/tool | Recover through Five's visible parent-child edge and Six's resource ownership; unsupported hidden paths cannot execute. |
| Stop requested but unconfirmed; lease/resource loss | Close dispatch and observe exact owned processes and effects; local disappearance does not prove remote quiescence. |
| Unreadable custody or observation gap | Preserve input and last cursor, surface the gap on the existing work/status path and reconcile; never reinterpret as empty. |

Each adapter binds every row to its actual evidence source before activation. Protected quiet
waits have an operation, condition and finite observation horizon; expiry removes the exemption,
not grants kill permission. Account optimization cannot interrupt healthy or unknown busy work.
A confirmed wedge needs current correlated evidence and an admitted action, not a `recovery`
caller label. One failed self-heal episode produces bounded actionable notice; routine churn
stays on the pull surface. Ordinary workers cannot consume Eleven's reachability reserve.

# Measurement and spend foundation

This package owns observational normalization, deterministic quantity resolution,
cross-instance aggregation, attribution presentation, pure resource/burn arithmetic,
bounded reads and disposable caches. It creates no constitutional type and exposes no
admission, placement, throttle, retry, routing, standing, effect or mutation operation.

The production ingestion, pricing, qualified accounting, benchmark, process-observer,
operator-surface and spend-control seams named by Part 16 remain dark until their owner
contracts land. `measurement.declarations.json` records that posture; an unavailable
owner seam is never represented by a package-local substitute.
